# 训练与评估契约

## 入口

保留独立训练与评估入口。训练入口可选择 `tabular` 或 `dqn`，但一次进程只训练一种算法；禁止并行启动两个独立训练，以避免重复加载风场数据。评估入口在同一套固定场景中比较随机、表格 Q 与 DQN。

## 共同实验条件

两种训练共享风场文件集、物理参数、起始帧采样规则和训练随机种子。训练和评估都从同一随机起始帧范围采样，不划分留出帧；为避开风场初始瞬态，采样范围从稳定后的第 60 帧开始。评估用固定评估种子在运行开始时生成一组场景，因此同一配置下可复现。

风场幅值缩放以三维风矢量 RMS 与中位迎角、零滚转稳态空速之比定义，目标比值为 `0.5`。缩放仅改变速度幅值，不改变风场时间演化。

表格 Q 与 DQN 使用完全相同的环境奖励：`u_z + w_a * a_z`，其中垂直风速 `u_z` 系数固定为 1，垂直风加速度权重 `w_a` 由配置控制。不包含高度变化或生存项。

## 运行与验收

完整训练步数不得超过改造前默认训练步数的 50%。先以短训练验证流程，再串行执行两种算法的完整训练，可使用 GPU。`reward_sweep.py` 依次执行 `1:1`、`1:3`、`1:5` 的六次训练，并在同一固定评估场景上汇总比较。

旧模型、Q 表和训练产物不属于兼容性契约。

## 动态 PPO 实验

动态 PPO 使用独立的非稳态环境，不和上述稳态表格 Q/DQN 共享动作、观测或奖励。它仍使用相同风场文件、风场倍率、随机起始帧范围和固定评估种子，但在相邻风场帧间插值。训练只能启动一个环境实例；评估在相同场景中比较随机、定速定滚转与 PPO，并同时报告高度和总能量变化。
