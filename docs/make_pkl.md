# `make_pkl.py`（旧策略生成器）

该脚本从硬编码的 7 行规则网格生成三个手工 Q 表，并绘制对应策略图。它只向 9 动作空间的中性攻角行写入偏好动作。

## 当前限制

当前 `config.py` 的 `BANK_BINS` 为 5，而该脚本固定使用 7 个滚转分箱及旧角度范围。因此生成的 Q 表与当前 `GliderEnv` 的观测形状不兼容，不能直接用于 `glider_train.py`、`eval_all.py` 或当前环境。

保留它仅用于复现历史规则策略。若需要可用的基线策略，必须先依据当前 `config.py` 的状态和动作契约重建规则表，而不是修改或复用这里的硬编码网格。
