# 配置

`config.py` 是主滑翔机工作流的唯一共享配置来源。环境、训练和评估应导入其中的参数，而不是复制常量或采样逻辑。导入模块时会创建项目内的 `q_table/` 和 `trainresult/` 目录。

## 分组

- 路径与输入：项目根目录、风场目录、模型目录、结果目录、极线基名和自然排序函数。
- 飞行器与空间：质量、参考面积、翼展、三维域尺寸。
- 共同实验条件：训练种子、评估种子、训练算法默认值和稳定起始帧区间；`sample_start_frame(rng)` 是所有主流程的唯一帧采样函数。
- 稳态环境：迎角和滚转分箱、传感器分箱与迟滞、RL 步长、积分数和风场换帧频率。
- 动态环境：RK4 积分步长、每帧飞行时间、迎角与滚转的命令范围/一阶响应/速率限制、低空速气动保护阈值、数值发散 TAS 上限、高度边界、四维观测标准化预采样步数、动作饱和判定、checkpoint 间隔、episode 报告间隔、基线命令与离散动作级数。
- 风场尺度与稳态奖励：三维风速 RMS 对典型空速比、操纵阻力倍率、垂直风加速度的单次权重和权重扫描列表。
- 训练：表格 Q、稳态 DQN、动态 PPO 和动态 DQN 的默认训练预算及各自优化参数；动态训练 checkpoint 间隔由各训练器使用的 `DYNAMIC_CHECKPOINT_INTERVAL` 定义，另包括 PPO 的 squashed-action 数值常量。
- 评估：`N_EVAL_EPISODES`。

风场实际倍率不是配置常量，而是环境使用风场数据和极线计算得到的派生值。模型名、CSV 路径和图像路径主要由各自训练或评估模块定义；只有稳态表格 Q 和稳态 DQN 的默认最终模型路径在配置中定义。
