# `glider_dynamic.py`

## 职责

实现供 PPO 使用的非稳态三维质点滑翔机环境，不修改 `glider_discrete_simp.py` 的稳态查表环境。

## 动力学契约

状态包含位置、地速、迎角与滚转角。相对空速为 `v_air = v_ground - wind`；根据极线的 `CL/CD` 实时计算升力和阻力，再积分地速与位置。空速、下沉率与转弯均是积分结果，不从稳态表直接取值。

风场时间以现有的一帧约两秒飞行时间推进，并在相邻 HDF5 帧间线性插值。水平坐标周期回绕；高度到达配置的上下边界或空速低于失速阈值时结束。

## 控制与观测

环境接收 `[speed, roll]`，两个分量均在 `[0, 1]`：

- `speed=0/1` 分别命令最大/最小迎角；实际迎角按一阶响应和速率限制变化，因此该量是低速到高速的偏好指令，而不是稳态空速查表。
- `roll=0/1` 线性映射为最小/最大滚转目标角，实际滚转同样采用一阶响应和速率限制。

观测为 float32 的 `[total_energy_vario, wingtip_normal_wind_difference]`，单位均为 `m/s`。第一项是 `d(g*h + 0.5*V_TAS^2)/dt/g` 经一阶低通后的总能量升降率；第二项是两翼尖局部风速差在升力法向的投影，是滚转气流线索而非完整刚体滚转力矩。

每个 RL 步的奖励是总能量高度增量 `delta(g*h + 0.5*V_TAS^2)/g`。评估同时报告高度变化和总能量高度变化。
